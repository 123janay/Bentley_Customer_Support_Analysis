Bentley Systems – Customer Support Data Analysis (SQL)

Project Overview

This project focuses on data quality assessment, data cleaning, and customer support analysis using SQL Server. The dataset is simulated and created for educational and portfolio purposes.

Objectives

Identify data quality issues in raw datasets.

Investigate missing values and duplicate records.

Detect inconsistent formats and invalid values.

Clean and validate data using SQL.

Analyze customer support performance.

Generate business insights using SQL queries.

Tools

Microsoft SQL Server

SQL Server Management Studio (SSMS)

SQL

GitHub

Project Workflow

Create database and tables.

Import raw data.

Perform data quality checks.

Clean the raw data.

Import cleaned data into final tables.

Perform SQL analysis.

Document findings and insights.
